# SHL Assessment Recommender

A conversational AI agent that helps hiring managers find the right SHL assessments through natural dialogue.

## Quick Start (5 minutes)

### Prerequisites
- Python 3.11+
- A free API key from one of: [Google AI Studio](https://aistudio.google.com/app/apikey) (recommended) | [Groq](https://console.groq.com) | OpenAI

### 1. Clone and install

```bash
git clone <your-repo-url>
cd shl-recommender

python -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate

pip install -r requirements.txt
```

### 2. Configure environment

```bash
cp .env.example .env
# Edit .env and add your API key
```

**.env** (minimum required):
```
LLM_PROVIDER=google
GOOGLE_API_KEY=your_key_here
```

### 3. Scrape the catalog (run once)

```bash
python scrape_catalog.py
```

This fetches all Individual Test Solutions from `shl.com` and saves them to `data/shl_catalog.json`. Takes ~5-10 minutes on first run. The FAISS index is built automatically on first server start.

### 4. Start the server

```bash
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

### 5. Test it

```bash
# Health check
curl http://localhost:8000/health

# Sample conversation turn
curl -X POST http://localhost:8000/chat \
  -H "Content-Type: application/json" \
  -d '{
    "messages": [
      {"role": "user", "content": "I am hiring a Java developer who works with stakeholders"},
      {"role": "assistant", "content": "What is the seniority level?"},
      {"role": "user", "content": "Mid-level, around 4 years experience"}
    ]
  }'
```

## API Reference

### `GET /health`

Returns service readiness.

```json
{"status": "ok", "catalog_size": 423}
```

### `POST /chat`

**Request:**
```json
{
  "messages": [
    {"role": "user", "content": "..."},
    {"role": "assistant", "content": "..."},
    {"role": "user", "content": "..."}
  ]
}
```

**Response:**
```json
{
  "reply": "Here are 5 assessments that fit a mid-level Java developer...",
  "recommendations": [
    {
      "name": "Java 8 (New)",
      "url": "https://www.shl.com/solutions/products/product-catalog/view/java-8-new/",
      "test_type": "K"
    }
  ],
  "end_of_conversation": false
}
```

**Rules:**
- `recommendations` is `[]` when agent is clarifying or refusing
- `recommendations` has 1-10 items when agent provides a shortlist
- `end_of_conversation` is `true` only when the agent considers the task complete
- All URLs are from the scraped SHL catalog — no hallucinated links

## Deployment

### Option A: Render (Free, recommended)

1. Push your code to GitHub (include `data/shl_catalog.json` OR set `buildCommand` to run the scraper)
2. Create a new **Web Service** on [render.com](https://render.com)
3. Connect your GitHub repo
4. Render auto-detects `render.yaml`
5. Set `GOOGLE_API_KEY` in Render dashboard → Environment
6. Deploy — your URL will be `https://your-service.onrender.com`

### Option B: Railway

```bash
railway login
railway init
railway up
railway variables set GOOGLE_API_KEY=your_key LLM_PROVIDER=google
```

### Option C: Docker

```bash
docker build -t shl-recommender .
docker run -p 8000:8000 \
  -e GOOGLE_API_KEY=your_key \
  -e LLM_PROVIDER=google \
  shl-recommender
```

## Evaluation

Run the built-in evaluation suite against a running server:

```bash
# Full evaluation
python evaluate.py --url http://localhost:8000

# Behavior probes only (fast)
python evaluate.py --url http://localhost:8000 --probes-only

# Verbose output
python evaluate.py --url http://localhost:8000 --verbose
```

**Metrics reported:**
- Schema compliance (every response)
- Recall@10 (fraction of expected assessments in top-10)
- Behavior probe pass rate (refusal, clarification, dedup, etc.)

## Troubleshooting

**`FileNotFoundError: Catalog not found`**
→ Run `python scrape_catalog.py` first.

**`TimeoutError` on LLM calls**
→ The evaluator has a 30s timeout. If you hit this, switch to Groq (`LLM_PROVIDER=groq`) which is faster.

**Empty recommendations on valid queries**
→ Check that `data/shl_catalog.json` was scraped successfully and has >100 items.

**`faiss` import error on Apple Silicon**
→ Install with: `pip install faiss-cpu --no-binary faiss-cpu`
